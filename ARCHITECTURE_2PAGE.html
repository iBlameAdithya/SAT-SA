1.0 Scope Boundary & Air-Gapped Solution Architecture

SAT-SA is an air-gapped supervisory analytics capability engineered to examine periodic submissions of SOC alert and case-management records from Critical Sector Entities (CSEs). Strict Out-of-Scope Guarantee: SAT-SA does not function as an operational SOC, SIEM, real-time telemetry collector, or multi-tenant monitoring platform. It operates entirely offline inside an NCIIPC-controlled environment with zero outbound network sockets, zero cloud relays, and zero externally hosted AI APIs.

2.0 Functional Design & Modular Processing Pipeline

1. Ingestion & Sanitization ETL

Streaming parser for CSV & JSON datasets. Header-order agnostic, trims whitespace, validates data types, and computes SHA-256 batch fingerprints.

2. Forensic Analytics Core RUST

Executes Execution Gap and Negative Space detectors in parallel threads. Deterministic math ensures byte-for-byte reproducibility.

3. Audit & Reporting Vault EXPORT

Generates signed PDF examination reports, machine-readable JSON packages, and seals all telemetry in a cryptographic Merkle root hash.

3.0 Operational Data Requirements (Privacy-Preserving Metadata)

To eliminate risks associated with handling classified or sensitive operational data, SAT-SA operates strictly on non-sensitive structural metadata:

  • Alert Metadata: alert_id, entity_id, asset_id, subnet, rule_name, category, severity, timestamp, mitre_tactic, mitre_technique.
  • Case Management Records: case_id, investigator_id, created_at, closed_at, duration_seconds, status, escalated, escalated_at, resolution_notes.
  • Asset & Subnet Inventories: Declared crown-jewel operational CIDRs (e.g. SCADA 10.200.0.0/16, Core Banking 10.100.0.0/16).
4.0 Supervisory Analytics Methodology: Unmasking Hidden Weaknesses

Execution Gaps (Procedural Gaming) GAPS

  • Sub-60s Ticket Closure: Identifies high-severity tickets closed in ≤ 60s without investigation. Flagged when > 20% of queue.
  • Unescalated Critical Incidents: Flags Tier-1 gatekeeping where High/Critical alerts are closed without Tier-2/CSIRT escalation (> 15%).
  • Remediation Deficit: Tracks repeated alerts on the same critical asset (≥ 5 occurrences) indicating failed root-cause resolution.
  • Benford's Law Chi-Square (χ²): Detects scripted ticket durations deviating from logarithmic distribution ($p < 0.01$).
  • MinHash LSH Note Collusion: Identifies copy-paste boilerplate notes across analysts using 3-gram shingles ($J \ge 0.75$).
  • Poisson Burst Windowing: Exposes shift-end ticket dumping (≥ 5 closures in 5 mins with mean duration ≤ 120s).

Negative Space (Omission & Blind Spots) SILENCE

  • Missing Threat Categories: Flags total absence of expected threat classes (MALWARE, RANSOMWARE, EXFILTRATION). Missing ≥ 3 triggers alert.
  • Shannon Information Entropy Collapse: Computes alert category entropy $H(X)$. A drop below $\hat{H} < 0.35$ proves SIEM rule silencing.
  • MITRE ATT&CK Matrix Deficit: Audits density across 11 core tactics (TA0001-TA0040). Coverage < 50% flags systemic blind spots.
  • Subnet Telemetry Blackout: Matches traffic against registered crown-jewel CIDRs. Active subnets with 0 alerts are flagged.
  • Anomalously Low Workload: Identifies CSEs reporting alert volumes disproportionately lower than peer scale ($Z < -2.0$).

5.0 Mathematical Formulations & Forensic Algorithms

Benford's Law Chi-Square Engine

Natural triage durations span orders of magnitude: $P(d) = \log_{10}(1 + 1/d)$ for $d \in \{1..9\}$. Automated closures skew distributions.

χ² = ∑ (O_d - E_d)² / E_d,   df = 8,   p = e^(-u)(1 + u + u²/2 + u³/6)

Threshold: If χ² > 20.090 ($p < 0.01$), flag Systemic Duration Fabrication.

MinHash Locality-Sensitive Hashing

Tokenizes resolution text into character 3-grams. Applies $K=32$ linear hash functions $h_k(x) = (a_k \cdot x + b_k) \pmod{2^{32}-5}$.

J(A, B) ≈ (1/K) ∑ I[S_k(A) == S_k(B)] ≥ 0.75

Clusters boilerplate resolution collusion across investigators in $O(N)$ time.

Shannon Information Entropy H(X)

Measures categorical alert dispersion across $k$ security categories:

H(X) = -∑ p_i log&sub2;(p_i),   H_hat = H(X) / log&sub2;(k)

Normalized entropy collapse ($\hat{H} < 0.35$) flags SIEM Rule Silencing.

Peer Z-Score & Composite Risk Index

Normalizes entity metrics against sector peer distributions:

Z_e = (X_e - μ) / σ;   Risk = ∑ W_f × Conf_f + Penalties

Ranks CSEs by composite risk (0-100) to prioritize on-site inspections.

6.0 Statutory Compliance & Cryptographic Chain-of-Custody

CERT-In 6-Hour Statutory SLA Auditor: Pursuant to Section 70B(6) of the IT Act 2000 and CERT-In Directions 2022, SAT-SA calculates incident escalation latency $\Delta t = t_{\text{escalated}} - t_{\text{detected}}$ for all High/Critical alerts. Breaches ($> 21,600\text{s}$) generate actionable statutory findings.
RFC 6962 SHA-256 Merkle Tree Integrity Seal: All ingested alerts, case tickets, and intermediate findings are hashed into a binary Merkle tree ($L_i = \text{SHA-256}(0x00 \parallel record_i)$). The resulting Merkle Root Hash is anchored to an append-only ledger, guaranteeing Section 65B Indian Evidence Act admissibility.

9.0 Explainability & Supervisory Decision Support

SAT-SA is explicitly built to support, not replace, supervisory judgement. Every finding generated is fully transparent: it states the exact rule code, mathematical formula applied, confidence level, human-readable rationale, and provides direct drill-down links to the underlying alert IDs, case tickets, and investigator IDs. Examiners receive an objective risk ranking that prioritizes scarce manual review hours toward the highest-risk entities and most severe operational vulnerabilities.
